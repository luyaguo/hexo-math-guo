# 第一章 函数极限与连续

## 一、函数的概念

> 设  $x$  与  $y$  是两个变量，  $D$  是一个给定的数集，若对于每一个  $x \in D$ ，按照一定的法则  $f$ ，有一个确定的值  $y$  与之对应，则称  $y$  为  $x$  的**函数**，记作  $y = f(x)$ ，称  $x$  为**自变量**，  $y$  为**因变量**，称数集  $D$  为此函数的**定义域**，定义域一般由实际背景中变量的具体意义或者函数对应法则的要求确定，称  $\{f(x) \mid x \in D\}$  为**值域**。


### 1 单值函数

事实上，上述定义的函数是**单值函数**，若给一个  $x_{1}$ ，对应一个  $y_{1}$  ；给另外一个  $x_{2}$ ，对应另外一个  $y_{2}$ ，这叫**一对一**。若给定  $x_{1}， x_{2}$  (  $x_{1} \neq x_{2}$  )，它们对应同一个  $y$ ，则称**多对一**，**所以函数可以一对一，也可以多对一，这叫单值函数**。


### 2 多值函数

若一个  $x$  对应一个  $y_{1}$ ，又对应另一个  $y_{2}$ ，也就是**一对多，这叫多值函数**。 它不在上述定义中。

> 我们的研究对象主要是单值函数.



### 3 如何判断 $y = f(x)$ 是否为单值函数？

> **铅锤划线法**：做铅锤直线，若任意一条铅锤直线与 $f( x )$ **至多有一个交点**，则 $f( x )$ 为单值函数。



例1.1 设  $f\left(x + \frac{1}{x}\right) = \frac{x + x^{3}}{1 + x^{4}}$， $x \geqslant 2$  ，则  $f( x ) =$___。



解：$f\left(x + \frac{1}{x}\right) = \frac{x + x^{3}}{1 + x^{4}} = \frac{x + \frac{1}{x}}{x^{2} + \frac{1}{x^{2}}} = \frac{x + \frac{1}{x}}{\left(x + \frac{1}{x}\right)^{2} - 2}$，  于是  $f(x) = \frac{x}{x^{2} - 2}$


例1.2 设函数  $f\left(x\right)$  的定义域为  $(0， + \infty)$  ，且满足  $2f(x) + x^{2}f\left(\frac{1}{x}\right) = \frac{x^{2} + 2x}{\sqrt{1 + x^{2}}}$  则  $f\left(x\right) =$___。



解：由  $2f(x) + x^{2}f\left(\frac{1}{x}\right) = \frac{x^{2} + 2x}{\sqrt{1 + x^{2}}}$  得  $2f\left(\frac{1}{x}\right) + \frac{1}{x^{2}} f(x) = \frac{\frac{1}{x^{2}} + \frac{2}{x}}{\sqrt{1 + \frac{1}{x^{2}}}} = \frac{\frac{1 + 2x}{x^{2}}}{\frac{\sqrt{1 + x^{2}}}{x}} = \frac{1 + 2x}{x\sqrt{1 + x^{2}}}$  结合以上两式，消去  $f\left(\frac{1}{x}\right)$  可得  $f(x) = \frac{x}{\sqrt{1 + x^{2}}}$



> **交叉相消法：若给  $f(x) + x f(- x) = x$  ，应学会写  $f(- x) - x f(x) = - x$  ，消去  $f(- x)$  ，得  $f(x) = \frac{x + x^{2}}{1 + x^{2}}$**



## 二、反函数

> 设函数  $y = f(x)$  的定义域为  $D$  ，值域为  $R$  .如果对于每一个  $y\in R$  ，必存在唯一的  $x\in D$  使得  $y = f(x)$  成立，则由此定义了一个新的函数  $x = \phi (y)$  ，这个函数称为函数  $y = f(x)$  的**反函数**，一般记作  **$x = f^{- 1}(y)$**  它的定义域为  $R$  ，值域为  $D$  .相对于反函数来说，原来的函数也称为**直接函数**。



### 1 概念解析

第一，**严格单调函数必有反函数（充分条件）**。比如函数  $y = x^{2}(x\in [0， + \infty))$  是严格单调函数，故它有反函数  $x = \sqrt{y}$

第二，**反函数和直接函数的图形是完全重合的**。若把  $x = f^{- 1}(y)$  与  $y = f(x)$  的图形画在同一坐标系中，则它们完全重合。

第三，只有把  $y = f(x)$  的反函数  $x = f^{- 1}(y)$  写成  $y = f^{- 1}(x)$  后，它们的图形才关于  $y = x$  对称（前提：符合铅锤画线法），事实上这也是字母  $x$  与  $y$  互换的结果。



### 2 概念扩展

第一，**有反函数的函数不一定是单调函数**。

比如  $f(x) = \left\{ \begin{array}{l l} {x，  x \geqslant 0，} \\ {\frac{1}{x}，  x < 0，} \end{array} \right.$  其图像如图所示，其反函数即为  $f(x)$  本身，但  $f(x)$  不是单调函数。

![](images/017e4346dfb2c1fefc1c27b7ed7563d0f4d1cc55eacfd9bf80a4a2e330d1f425.jpg)

第二，已知 $y = f(x)$，其反函数为：$x = f^{-1}(y)$，关于 $y = x$ 对称函数 $y = f^{-1}(x)$，则有 $ff^{-1}(x) = x$，$f^{-1}f(x) = x$ 。比如：
$$
\mathbf{e}^{x \ln2} = \mathbf{e}^{\ln2^{x}} = 2^{x}
$$


### 3 如何判断 $y = f(x)$ 是否为反函数？

> **水平画线法（数形结合）：$y = f(x)$ 符合铅锤画线法的条件下，做一条水平直线，若任意一条直线与 $f(x)$ 至多一个交点，则 $f(x)$ 必有反函数。**
> 
> **铅锤直线定单多，水平直线定反直**

例1.3 求函数  $y = f(x) = \ln \left(x + \sqrt{x^{2} + 1}\right)$  的反函数  $f^{- 1}(x)$  的表达式及其定义域。



解：直接由  $y = \ln \left(x + \sqrt{x^{2} + 1}\right)$  解出  $x = f^{- 1}(y)$  会很麻烦，现采用下述方法：
$$
\begin{array}{r l} -y & {= -\ln \left(x + \sqrt{x^{2} + 1}\right)} {= \ln \frac{1}{x + \sqrt{x^{2} + 1}}} \\ & {= \ln \frac{\sqrt{x^{2} + 1} - x}{\left(\sqrt{x^{2} + 1} + x\right)\left(\sqrt{x^{2} + 1} - x\right)}} \\ & {= \ln \left(\sqrt{x^{2} + 1} - x\right)} \end{array}
$$

所以

$$
\mathbf{e}^{-y} = \sqrt{x^{2} + 1} -x \tag{1}
$$

再由  $y = f(x)$  的表达式有

$$
\mathbf{e}^{y} = \sqrt{x^{2} + 1} +x \tag{2}
$$
(2) - (1)  ，得
$$
x = \frac{1}{2}\left(\mathbf{e}^{y} - \mathbf{e}^{-y}\right)
$$

交换上式中  $x， y$  的位置后就是  $y = f(x)$  的反函数，即

$$
y = f^{-1}(x) = \frac{1}{2}\left(\mathbf{e}^{x} - \mathbf{e}^{-x}\right)， - \infty < x< +\infty
$$

>
> **$y = f(x)$  的反函数的写法：$x = f^{- 1}(y)$  或者  $y = f^{- 1}(x)$**
>

第三，以后会知道如下 3 个重要结论：

>
> 结论一：**$x\rightarrow 0$  时，  $\ln {\Bigl (}x + \sqrt{x^{2} + 1}{\Bigr)}\sim x$**
> 
> 结论二：**$\left[\ln \left(x + \sqrt{x^{2} + 1}\right)\right]^{'} = \frac{1}{\sqrt{x^{2} + 1}}$  于是  $\int \frac{1}{\sqrt{x^{2} + 1}}\mathrm{d}x = \ln \left(x + \sqrt{x^{2} + 1}\right) + C.$**
> 
> 结论三：**由于  $y = \ln \left(x + \sqrt{x^{2} + 1}\right)$  是奇函数，所以 $\int_{- 1}^{1}\left[\ln \left(x + \sqrt{x^{2} + 1}\right)\right]\mathrm{d}x = 0$ ，于是  $\int_{- 1}^{1}\left[\ln \left(x + \sqrt{x^{2} + 1}\right) + x^{2}\right]\mathrm{d}x = \int_{- 1}^{1}x^{2}\mathrm{d}x = \frac{2}{3}$** 。

## 三、复合函数

> 设函数  $y = f(u)$  的定义域为  $D_{1}$  ，函数  $u = g(x)$  在  $D$  上有定义，且  $g(D)\subset D_{1}$  ，则由 **$y = f[g(x)](x\in D)$** 确定的函数称为由函数  $u = g(x)$  和函数  $y = f(u)$  构成的**复合函数**，它的定义域为  $D$  ，  $u$  称为**中间变量**。考生要掌握复合的方法。
>


例题一：设  $f(x) = x^{2}$  ，$f[\phi (x)] = - x^{2} + 2x + 3$  ，且  $\phi (x)\geqslant 0$  ，求  $\phi (x)$  及其定义域与值域。



解：由题设条件知，  $f[\phi (x)] = \phi^{2}(x) = - x^{2} + 2x + 3$  ，于是  $\phi (x) = \sqrt{- x^{2} + 2x + 3}$ 。
由  $- x^{2} + 2x + 3\geqslant 0$  ，即  $(x - 3)(x + 1)\leqslant 0$  ，知  $\phi (x)$  的定义域为[- 1， 3] 。
又  $\sqrt{- x^{2} + 2x + 3} = \sqrt{- (x - 1)^{2} + 4}$  ，当  $x = 1$  时，  $\phi (1) = 2$  为最大值，
显然  $\phi (- 1) = \phi (3) = 0$  为最小值，故  $\phi (x)$  的值域为[0， 2]。

## 四、隐函数

> 设方程  $F(x，y) = 0$  ，若当  $x$  取某区间内的任一值时，总有满足该方程的唯一的值  $y$  存在（单值函数），则称方程  $F(x，y) = 0$ 在上述区间内确定了一个隐函数  $y = y(x)$ 。

如  $x + y^{3} - 1 = 0$  就表示一个隐函数，且可显化为  $y = \sqrt[3]{1 - x}$ ； 再如  $\sin (x y) = \ln{\frac{x + \mathbf{e}}{y}} + 1$  也表示一个隐函数，但不易显化。

一般来说，由  $F(x，y) = 0$  所确定的隐函数求  $y(x_{0})$  ，若代入  $x_{0}$  易求出  $y(x_{0})$  ，则直接求之；若不易求出  $y(x_{0})$  ，则用**观察法**。如:

$①$  设函数  $y = y(x)$  由方程  $\ln y - \frac{x}{y} +x = 0$  确定，当  $x = 2$  时，  $y(2) = 1$ （ $\ln y - \frac{2}{y} +2 = 0$  显然可看出，  $y = 1$  时成立）

$②$  设函数  $y = y(x)$  由方程  $\ln y + \mathbf{e}^{y - 1} = \frac{x}{2}$  确定，当  $x = 2$  时，  $y(2) = 1$ （$\ln y + \mathbf{e}^{y - 1} = 1$  显然可看出，  $y = 1$  时成立）
